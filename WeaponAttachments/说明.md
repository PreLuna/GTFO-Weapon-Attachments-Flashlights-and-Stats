# WeaponAttachments 说明

## 身份

- GUID：`PreLuna.WeaponAttachments`；版本：0.8.0；源码 managed。
- 主文档：[README](../README.md)；数据包为 `WeaponDataCustom 1.0.8`。

## 功能

自定义武器配件、数值/光照/数据包加载；依赖 GTFO-API、MTFO、ModifierAPI、AmorLib、EWC、StatShower 等运行前置。

## ModControl

- **当前没有 ModControl 页面（明确缺口）**。
- 有 4 个 `Config.Bind`：`General/Enabled`、`Diagnostics/WriteStartupReport`、`Diagnostics/VerboseDependencyLog`、`Runtime/DataPackId`。
- `DataPackId` 会在启动时校验，非法值会使插件拒绝启动，不建议开放写入。

## 依赖与兼容

- 硬依赖：GTFO-API、MTFO、ModifierAPI、AmorLib、ExtraWeaponCustomization、WeaponStatShower。
- 软依赖：PartialData（MTFO PartialBlocks）。
- 版本/范围以 `repo.json` 和 README 依赖表为准；不可把管理分组当硬依赖。

## 验证/安装

- 0.8.0 现装；本轮未改代码、未加页面。
- 安装需同时满足数据包/运行前置；个人 CFG 不随安装包分发。

## 边界

有配置项但未接面板；补页前需决定 `DataPackId` 只读和 3 个布尔/诊断项。
