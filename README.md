# GTFO-Weapon-Attachments-Flashlights-and-Stats

Weapon attachments, flashlight customization, and weapon data for GTFO. 武器配件、手电与武器数值配置。

| 模组 | 版本 | 维护输入 |
| --- | --- | --- |
| WeaponAttachments | 0.8.0 | 源码 |
| FlashlightCustom | 1.0.1 | 冻结 DLL＋身份迁移 |
| WeaponDataCustom | 1.0.8 | 当前游戏数据 |

## 下载和安装

普通玩家请在 [Releases](https://github.com/PreLuna/GTFO-Weapon-Attachments-Flashlights-and-Stats/releases) 下载安装 ZIP；首次发布前该页面没有安装包。GitHub 的 Source code ZIP 用于开发。
退出游戏后，将安装 ZIP 中的 `BepInEx` 合并到已安装 BepInEx IL2CPP 的 GTFO 游戏目录。替换同功能旧版本，避免同时加载两个版本。个人配置不包含在安装包中。

本仓库的运行前置见 [repo.json](repo.json) 中各模组的 `DependencyGuids`；外部前置须自行安装。同仓收纳表示共同维护，具体依赖以该清单为准。

开发、同仓关联和跨仓联动见 [DEVELOPMENT.md](DEVELOPMENT.md)，来源见 [NOTICE.md](NOTICE.md)。
